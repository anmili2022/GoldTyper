# 金蝶打字通 · GoldTyper

面向 FFXIV 国服 Dalamud 的「魔光键影」打字助手。自动识别可见词条、填写答案并立即提交，让重复答题、再次参加和成绩记录集中在一个面板中完成。

本项目由 AI 制作，功能持续完善中；构建通过不代表所有流程均已完成游戏内验证。

## 功能

- **自动答题**：识别可见词条，填写并校验后立即提交。两次答题之间采用可配置的随机间隔，默认 500–5000 ms。
- **目标优先策略**：提供读条优先和近距离优先开关。近距离优先以词条组件的画面深度为依据，不表示距玩家的精确米数；读条与词条的关联仍需修正，可能出现误判。
- **活动输入**：可在答题前发送随机英文字母和实体回车，确认输入清空后继续答题。需要游戏处于前台，实际防 AFK 效果尚未确认。
- **自动再次参加**：可在结算后退出，与已记录且位于附近的入口 NPC 交互，申请参加并确认「魔光键影」出发。
- **每轮简报**：结算时保存角色名@归属服务器、开始时间、结束时间、本人总分和用时，可从面板打开保存文件夹。
- **诊断工具**：支持调试日志、实时数据查看和手动快照，便于分析目标与读条行为。

## 使用

1. 输入 `/gt` 或 `/打字通` 打开面板。
2. 在「选项」中调整输入间隔和功能开关。防 AFK 活动输入、读条优先、近距离优先默认开启，自动再次参加默认关闭。
3. 点击「开始」运行，使用「暂停 / 恢复」和「停止」控制流程。
4. 如需自动再次参加，先在入口选中正确的 NPC，点击「记录当前选中的入口 NPC」，再开启「结算后退出并再次参加」。出本后需保持在该 NPC 的 5 米范围内。

关闭面板仅隐藏界面，自动流程会继续运行。点击「−」可缩为 280 × 180，点击「□」恢复原尺寸；窗口尺寸随 Dalamud 全局缩放调整。说明文字可通过悬停控件或标题旁的 `(?)` 查看。

简报、调试日志和手动快照保存在插件配置目录中，面板提供对应的「打开文件夹」按钮。简报计时从首次观察到本轮可输入开始；中途加载插件时仅统计采集时段。

## 验证范围

原生输入、提交、自动再次参加、简报与诊断功能均已接入，完整流程仍需持续实机回归。活动输入会额外提交一个字母，其成绩影响及防 AFK 效果尚未确认。发现异常时，可查看调试日志；需要分析场上目标时，在「测试工具」中点击「保存手动快照」。

自动输入属于自动化操作，可能违反游戏条款，请自行评估风险。

## 构建

```powershell
dotnet build GoldTyper.sln -c Release
```

产物：`output/GoldTyper.dll`。
